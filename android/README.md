# Android開発版

Android 8.0以降、64ビット（arm64-v8a / x86_64）向けの開発版です。
GB / GBCの既存Gambatteコアと、Windows版と同じblipper音声変換を使用します。

## ビルド

JDK 17または21、Android SDK Platform 35、Build Tools 36.0.0、
NDK 30.0.16248370、SDK CMake 4.1.2を使用します。
Gradle 8.12とAndroid Gradle Plugin 8.7.3を固定しています。

リポジトリ直下で次を実行します。

```powershell
.\build-android.ps1 -Offline
```

依存キャッシュがない環境では`-Offline`を省略します。
`ANDROID_HOME`と`JAVA_HOME`を指定できます。
APKは`android/app/build/outputs/apk/debug/app-debug.apk`です。
開発用のdebug署名を使用します。リリース署名鍵やGBWiz_appは変更しません。

## 初回起動

1. 保存フォルダ選択画面で`Documents`を選ぶと、その中に`GBWiz/Save`・`GBWiz/State`・`GBWiz/rom`を作成します。既存の`Documents/GBWiz`を直接選んでも構いません。
2. アプリ内ROM一覧からGB / GBCのROMを選択します。初期フォルダは`Documents/GBWiz/rom`です。
3. 別の場所のROMを使う場合は、ROM一覧の「ROMフォルダを変更…」で任意のフォルダを選びます。選択は次回も記憶します。
4. タッチボタンまたはコントローラーで操作します。複数同時押しに対応します。

Androidのシステムファイル選択（Storage Access Framework）で選択したフォルダに保存します。
フォルダ利用権限は再起動後も保持します。インターネット権限やストレージ全体へのアクセス権限は要求しません。
文書プロバイダーによって初期フォルダ指定が無視される場合は手動で移動してください。

## 操作・保存

- 機能メニュー・ROM一覧は項目を直接タップ、または十字キー＋Aで操作できます。Bで戻ります。
- メニューのスロットとAB交換は左右、タッチでは項目の左側・右側で変更します。
- 機能メニューから5スロット保存・読込、AB交換、ROM選択、確認なしのリセット。
- 保存名はROM名から拡張子を除いた名前を使います。ハッシュ値は使用しません。
- 通常セーブは`Documents/GBWiz/Save/ROM名.sav`、ステートは`Documents/GBWiz/State/ROM名.slot1.state`〜`ROM名.slot5.state`。
- 旧形式のGBWiz直下・選択済み保存ルート直下のセーブも読み込みます。新規保存はSave／Stateへ行い、旧ファイルは削除しません。
- AB交換・選択スロットは保存フォルダ内の`settings.ini`。
- 保存フォルダのURIだけはAndroid内部設定に保持します。
- 通常セーブは10秒ごと・バックグラウンド移行時・ROM切り替え前・リセット前に保存。
- 通常セーブ・設定の書き込みはWiizを参考にした専用キューで実行し、同じファイルへの未処理スナップショットは最新分にまとめます。
- バックグラウンド移行・ROM切り替え・ステート読込・リセットでは保存完了を待ちます。保存失敗時の未処理データはメモリに保持し、次の保存操作で再試行します。
- 既存の保存を上書きする前に同名`.bak`を保存します。異常終了時の自動復旧は未実装です。
- 同名ROMは同じ保存先です。異なるゲームには別のROMファイル名を付けてください。

Androidゲームパッドの標準キーで右フェイスボタン=A、下=B、十字キー・Start・Select、
左スティック押し込み=メニュー、LT=スロット1保存、右スティック押し込み=スロット1読込を実装しています。
WiizのAndroid Switch Pro補正を参考に、Nintendo純正Pro（VID 057e / PID 2009）はAラベル=決定、Xboxは右のBラベル=決定となるよう、同じ物理位置に合わせています。
実物のXbox / Pro Controller接続は未検証です。

## 画面配置

Wiizの`sample/縦.png`・`sample/横.png`、`ControllerLayout.java`、`gamepad_input.hpp`を参考にしています。
縦画面は上にGB画面、その直下にリセット／SAVE 1／LOAD 1を横並びで配置し、左に十字キー、右に大きなSelect／Start／B／A。
横画面は中央にGB画面、左右に操作ボタンを配置します。
ステータスバー、切り欠き、ジェスチャー領域を避けて配置します。

## 検証

2026-10-28: ARM64 / x86_64のdebug APKビルド成功。
Pixel 9a（Android 17）へのインストールとActivity起動成功。
実機でのタッチ操作・音の聴感・Documentsへの保存は確認待ちです。

Androidエミュレータ（API 37 / x86_64）で`CoreTest.testGbAndGbcCore`が成功。
GB外伝1とGBC版Wizardry 1の180フレーム、ARGB映像、音声データ、ステートの往復・
不正ステート拒否、リセット時SRAM保持、通常セーブを渡した再起動を検証しています。
ROMはアプリAPK・テストAPKのどちらにも同梱しません。
テストROMはテスト端末上のアプリ専用cacheに別途配置します。

GB版外伝1～3とGBC版Wizardry 1～3で倍速（1.5／2／3／4倍）＋音声1倍に対応しました。メニューの「速度」を左右で変更します。
GBC版DQ3も実装済みで、2026-10-29にPixel 9aで全4倍率の音声クロックとリセット後の倍速動作を確認しました。実機のコア自動テストでフィールド移動・戦闘勝利・復帰まで操作し、スクロール修正後の58画面×4倍率がWindows版と一致しました。倍速時に方向キーを断続入力していたため歩行が停止していた問題を修正し、連続歩行とキーを離した後の映像も全4倍率で検証しました。音楽はユーザーの実機確認で特に問題なしとの結果のため、[フィールド曲の細かな周波数差](../docs/dq3-validation.md)の調査は優先度を下げています。
初回の倍速開始時はBGMが曲の先頭から再開します。新しく保存するステートはBGMの演奏位置と速度も復元します。
従来形式のステートではBGMは曲の先頭から再開します。[方式・検証範囲](../docs/turbo-audio.md)を参照してください。
外伝1の経験値／お金倍率を追加しました。機能メニューの「サポート」から、経験値とお金を別々に左右で変更します。
×1（通常）／×8／×16／×32／×64／×128／×256を選べ、次回起動・リセット後も設定を保持します。
対応する命令列が確認できない版や他作品では「対象外」と表示します。[方式・検証範囲](../docs/reward-support.md)を参照してください。
同じサポート画面の「作成ボーナス最大」をONにすると、外伝1の次の新規作成時に30ポイントを得られます。初期値はOFFで、設定は再起動・リセット後も保持します。
既に振り分け中のポイントや既存キャラクターは変更しません。[作成ボーナスの検証範囲](../docs/creation-support.md)を参照してください。
外伝1ではサポート→「キャラクターを選択」で登録番号・名前から対象を選び、次の画面で「全呪文習得」を実行します。全61呪文を習得して通常セーブに保存します。施設内・迷宮・キャンプでも利用できます。戦闘中は実行できません。
MPは変更しません。必要な場合は宿屋で休んでください。[全呪文習得の方式・検証範囲](../docs/spell-support.md)を参照してください。
GB版外伝1の起動ロゴスキップを追加しました。ROM起動・切り替え・リセット時に自動適用します。
「ロゴスキップ」でON／OFFでき、次回起動・リセットから反映します。
適用範囲と検証内容は[ゲーム別対応状況](../docs/game-support.md)を参照してください。
AndroidのUI・保存テストでは、8種類の縦横サイズの安全領域・重なり、Xbox/Pro配列、
キーと直接タップによるメニュー操作、専用文書プロバイダーによるSave／State保存・旧形式互換・任意ROMフォルダを検証します。
保存キューはスナップショットのコピー・順序・集約・失敗と再試行、音声は部分書き込み時のステレオ順序保持・一時停止時の破棄を検証します。
音声出力デバイスが途中で使えなくなった場合は、通知して無音で続行します。

サポート画面の「MP消費なし」を左右または項目の左右タップでON／OFFできます。全員共通で、キャラクター選択は不要です。現在MPの回復は行いません。[方式と検証範囲](../docs/mp-support.md)を参照してください。
対象選択後に「属性を善にする」「属性を中立にする」「属性を悪にする」をAまたはタップで実行できます。選択対象だけを変更して通常セーブへ保存します。[方式と検証範囲](../docs/alignment-support.md)を参照してください。
サポート画面の「善悪混合」を左右または項目の左右タップでON／OFFできます。キャラクターの属性を変えずに酒場で混合編成できます。[OFF時の扱い・保存・検証範囲](../docs/party-support.md)を参照してください。

低コスト展開として、外伝2にMP消費なし、外伝2・3に善悪混合のコア処理、GBC Wizardry 1〜3にロゴスキップを追加しています。ロゴスキップは既存の共通ON／OFF設定を使い、未知のタイトル状態では通常起動します。Windows全27テスト、Pixel 9aの起動・原作処理・操作8テストが成功しています。[対応表・検証範囲・保留項目](../docs/porting-status.md)を参照してください。0.1.0-rc1候補はこの展開前の状態として保持しています。
