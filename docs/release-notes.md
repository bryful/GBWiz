# GBWiz 0.1.3

2026-11-03。Windows x64、Android 8.0以降（arm64-v8a／x86_64）向けです。

## 0.1.2からの変更

- コントローラーのXにSTART、YにSELECTを追加。既存のStart／Select（＋／−）も使用できます。
- 機能メニューへ「X / Y 入れ替え」を追加。AB入れ替えとは個別に設定・保存できます。
- Windows／Androidの両方に対応。キーボード・タッチのSTART／SELECTは変更しません。

従来のマップ・移動、経験値／お金倍率、Wizardry支援、倍速、5スロットのステートセーブを継続します。
ソース・ROM・保存データ・秘密鍵・資格情報は同梱しません。操作はREADME.md、検証範囲はVALIDATION.mdを参照してください。
